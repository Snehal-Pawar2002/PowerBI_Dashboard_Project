# PowerBI_Dashboard_Project

HR Analytics Dashboard (Power BI)

Project Overview
This project is an HR Analytics Dashboard developed using Microsoft Power BI. The dashboard provides insights into employee demographics, salary distribution, attrition, department-wise performance, and workforce analytics.

Tools Used

Microsoft Power BI
Power Query
DAX
Data Modeling
Interactive Visualizations

Dataset Features

Employee ID
Employee Name
Department
Job Role
Gender
City
Salary
Performance Rating
Experience
Attrition


Dashboard KPIs
Total Employees: 20
Average Salary
Total Salary: 1M
Highest Salary: 120K
Lowest Salary: 40K

Visualizations

Department-wise Employee Count
Attrition Analysis
Gender Distribution
Average Salary by Department
Salary Analysis
City-wise Employee Distribution
Performance Analysis
Interactive Filters and Slicers


Key Insights

IT department has the highest number of employees.
Attrition rate is comparatively low.
Employee distribution is balanced across genders.
Salary varies across departments and job roles.
Performance and experience levels can be analyzed by city and department.
